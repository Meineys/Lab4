## Задание 1: Обработка результатов олимпиады
Скрипт: `task1.py`

Приложение читает данные из CSV-файла (`rez.csv`) с результатами олимпиады и отображает их в таблице (`QTableWidget`). 

**Функционал:**
*   **Фильтрация:** Реализованы выпадающие списки (QComboBox) для фильтрации данных по номеру школы и номеру класса. Фильтры могут работать совместно.
*   **Выделение призеров:** После применения фильтров программа автоматически находит 3 лучших результата (учитывая, что одно место могут делить несколько участников) и подсвечивает их строки:
    *   1 место - Золотой цвет
    *   2 место - Серебряный цвет
    *   3 место - Бронзовый цвет
*   **Отображаемые данные:** В таблице выводятся только Логин, ФИО и Суммарный балл.

## Задание 2: Управление базой данных фильмов
Скрипт: `task2.py`

Приложение для просмотра и редактирования базы данных фильмов SQLite (`films_db.sqlite`).

**Функционал:**
*   **Просмотр данных:** Таблица отображает содержимое БД. Для поля жанра выводится его текстовое название (через `JOIN` таблиц `films` и `genres`). Названия колонок генерируются динамически из курсора БД.
*   **Добавление записей:** Отдельное диалоговое окно (`task2_dialog.ui`) для ввода данных нового фильма.
*   **Редактирование записей:** Изменение данных выделенного фильма в том же диалоговом окне.
*   **Удаление записей:** Удаление выделенного фильма из БД.
*   **Валидация:** Обработка ошибок ввода:
    *   Проверка на пустое название.
    *   Запрет на отрицательную длительность.
    *   Проверка года (не больше текущего).
    *   Вывод предупреждений, если нажата кнопка редактирования/удаления, но не выбрана ни одна строка.

## Задание 3: Интерактивное рисование фигур
Скрипт: `task3.py`

Простое приложение для рисования фигур по клику мыши на форме.

**Функционал:**
*   **Левый клик (ЛКМ):** Рисует круг случайного цвета и размера в месте клика.
*   **Правый клик (ПКМ):** Рисует квадрат случайного цвета и размера.
*   **Пробел:** При нажатии клавиши `Space` в текущей позиции курсора мыши рисуется треугольник случайного цвета и размера (реализовано через отслеживание движения мыши `setMouseTracking`).

## Задание 5: Управление НЛО
Скрипт: `task5.py`

Мини-игра, где пользователь управляет картинкой НЛО с помощью стрелок на клавиатуре.

**Функционал:**
*   **Управление:** Клавиши-стрелки (Вверх, Вниз, Влево, Вправо) перемещают НЛО на фиксированный шаг.
*   **Телепортация через края:** Если НЛО выходит за правую границу окна, оно появляется слева (и наоборот для всех сторон).
*   **Standalone сборка:** Для этого задания предусмотрена сборка в независимый `.exe` файл с помощью `PyInstaller`.

## Задание 6: Каталог библиотеки с авторизацией
Скрипт: `task6.py`

Комплексное приложение для управления каталогом книг с системой пользователей.

**Функционал:**
*   **Авторизация и Регистрация:** При запуске открывается диалог логина (`task6_login.ui`). Можно войти под существующим аккаунтом или зарегистрировать новый.
*   **Безопасность:** Пароли в базе данных (`library.sqlite`) хранятся в захэшированном виде (SHA-256). Логины уникальны.
*   **Главное окно:** После входа открывается таблица с каталогом книг.
*   **Поиск:** Реализован поиск книг по Названию или по Автору (с помощью выпадающего списка).
*   **CRUD операции:** Возможность добавлять, изменять и удалять книги (через `task6_dialog.ui`).
*   **Отображение обложек:** При выборе книги в таблице, загружается её обложка (путь хранится в БД). Если путь не указан или файл не найден, отображается картинка-заглушка (`default.png`).
